# Fitbit Data Access

Read-only access to Fitbit health and fitness data for personal use through the Google Health API.

- [Homepage](https://salazar-prime.github.io/fitbit-data-access/)
- [Privacy policy](https://salazar-prime.github.io/fitbit-data-access/privacy.html)

This repository contains only the public information site and privacy policy. It contains no health records, authentication credentials, account-connection interface, or integration source code. The underlying personal-use integration is restricted to approved accounts.

The site uses plain HTML and CSS with no build step, JavaScript, analytics scripts, or remotely hosted fonts. GitHub Pages serves it from the root of the default branch.

For privacy questions or deletion requests, email [salazar.prime007@gmail.com](mailto:salazar.prime007@gmail.com). Do not post personal health information or credentials in public issues.
